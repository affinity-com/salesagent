Siteplug SSP API Configuration

Connect to the Siteplug SSP Tech API. You will need your API base URL and API key from your Siteplug account.

The base URL for the Siteplug SSP Tech API
X-API-Key header value for SSP API authentication. Leave blank to keep the existing key.
When enabled, media buys will require human approval before being activated in Siteplug
{# --- Affilizz Internal Text Ads API --- #}

Affilizz Internal Text Ads API

Optional. Connect to the Affilizz Internal Text Ads API to sync text_ad_search creatives automatically when media buys are approved. Requires an INTERNAL_API-scoped token from Affilizz. If not configured, text ad sync is skipped with a warning.

Base URL for the Affilizz Internal Text Ads API
ApiKey header value for Affilizz Internal Text Ads API authentication. Leave blank to keep the existing key.
{# --- Brand Agent Integration --- #}

Brand Agent Integration

Optional. Connect to the Brand Agent to resolve related domains (king_domains) for SDC campaigns. Required when products use campaign_type=SDC and no static related_domains are configured on the product.

Base URL of the Brand Agent REST API (no trailing slash, no /mcp)
Leave blank to keep the existing key.
Tenant scope for brand-agent queries (usually default)
